PQDIF chart data mapping

How an imported .pqd file becomes chart data, based on the supplied mapping document. This reference describes its File Analysis architecture; this page’s current viewer uses the JavaScript library and Chart.js. Live Modbus register data follows a separate path.

1. Decode and normalize

Import .pqdBinary file bytes containing observations, channels, and series.

Physical parserparse_pqdif_bytes()Decode PQDIF elements.
→
Semantic parseranalyze_pqdif()Map channel definitions and normalize samples. Apply raw × scale + offset when required by the storage method.
↓
Original samplesseries.rawValuesPreserved for data lineage.
Chart samplesobservations[o].channels[c].series[s].valuesThe normalized numeric array used by sample charts.
Selection cataloganalysis.seriesCatalogMetadata and IDs such as o0-c1-s0. No duplicate sample arrays.

2. Select a series and draw the chart

Eligibility → selection → source lookupRequire count > 1 and normalizationApplied === true. Resolve the selected o#-c#-s# catalog ID to the original series, then read series.values.
↓
TrendSelect an eligible non-Time series.series.values → SVG line chart.
Oscilloscope (OSC)Select an eligible Waveform series.series.values → SVG line chart. No additional RMS calculation or waveform reconstruction.
HarmonicsFirst eligible Response series, or a channel/quantity name containing harmonic, thd, or interharm.series.values → SVG bars. X = stored array index; Y = normalized value. Harmonic order is not inferred.

In the reference mapping, increment-encoded series are kept raw and excluded from plotting. Trend and OSC ignore non-finite samples and downsample displays above 1,800 finite points only for rendering; the original arrays remain unchanged.

4. Trend and OSC time-axis fallback

Use the first reliable source below. If it is unavailable, try the next step.

  1. Channel Time seriesSame channel and sample count; valueType === "Time" or unit === "timestamp".
  2. Filename + cadenceQ200 filename timestamp _YYYYMMDDThhmmss… plus cadence from metadata, such as Freq10s or 10min.
  3. Observation + cadencetimeStart or timeCreate plus the parsed cadence.
  4. Sample indexSample 0 through the final sample when reliable time data is unavailable.

Time-axis selection changes labels only; it does not change the plotted numeric values.
