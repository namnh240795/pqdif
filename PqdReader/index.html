PQDIF chart data mapping

How an imported .pqd file becomes chart data, based on the supplied mapping document. This page parses the selected PQDIF file directly. Choose an analysis type without selecting a device. ITIC lists the disturbance events recorded in the file and lets you inspect each event’s measured series; a standards-based ITIC compliance curve needs duration, magnitude, and compliance limits that are not present in every PQDIF file. Start/end controls filter by file timestamps and clip samples when a matching Time series is present. Live Modbus register data follows a separate path.

In the reference mapping, increment-encoded series are kept raw and excluded from plotting. Trend and OSC ignore non-finite samples and downsample displays above 1,800 finite points only for rendering; the original arrays remain unchanged.

4. Trend and OSC time-axis fallback

Use the first reliable source below. If it is unavailable, try the next step. The date filter uses absolute sample times reconstructed as observation start plus the channel Time value.

  1. Channel Time seriesSame channel and sample count; valueType === "Time" or unit === "timestamp".
  2. Filename + cadenceQ200 filename timestamp _YYYYMMDDThhmmss… plus cadence from metadata, such as Freq10s or 10min.
  3. Observation + cadencetimeStart or timeCreate plus the parsed cadence.
  4. Sample indexSample 0 through the final sample when reliable time data is unavailable.

Time-axis selection changes labels only; it does not change the plotted numeric values.
